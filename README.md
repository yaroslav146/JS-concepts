# Zápisky JavaScript 
Zápisky obsahují základy JavaScriptu, práci s proměnnými, podmínkami, cykly a funkcemi. Dále se věnují propojení JavaScriptu s HTML, manipulaci s prvky stránky a formulářovým prvkům.

Projekt je dobrovolným studijním projektem, jehož cílem je přehledně zpracovat probíranou látku a usnadnit její opakování.
